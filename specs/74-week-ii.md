## Reading — every row that is not `match`

The week reader is one composition drawn twenty-four times: twelve weeks, each
at the top of its row column (P1) and fully scrolled (P2). The app draws both
from one screen — `src/app/week/[week].tsx` — so the P2 frame is the P1 frame
with the row column scrolled to its end, which after this pass is exactly 320.

Every differing row on this frame belongs to one of these classes, and no other:

* **`radius: 50% → <n>px`.** React Native's `borderRadius` is a number, not a
  percentage. Every one is half the box's shorter side (`DECISIONS.md` D015).
* **`bg: <colour> → -` with the radius also going to `-`.** The scene band is a
  single `<Svg>`: every one of the canvas's positioned `<div>`s inside it is a
  `<Rect>`, `<Ellipse>` or `<Path>` there, so its paint lives on `fill` rather
  than on `background-color`, and the probe reads no background. The rect is
  identical; `src/components/journey/WeekScene.tsx` resolves the layer's own
  declared box into SVG user space before drawing it.
* **`radius: 50% 50% 0 0 / Npx …→ -`.** An elliptical corner radius has no
  React Native equivalent; each headland is drawn as an arc path
  (`domePath()`), same rect, same silhouette.
* **`shadow: … → -`.** A ring becomes a `stroke` on the same shape and a blurred
  drop shadow a soft radial under it, neither of which the probe reads as a
  `box-shadow`.
* **A `svg` wrapper reported as absent.** The canvas's inline bird `<svg>`
  carries its own 16 × 8 box; `react-native-svg` nests an `<Svg>` whose layout
  box collapses onto its content, so only the `<path>` inside reports a rect —
  and that path matches the canvas's to the tenth of a point.

The account: these frames draw a library on **day 12** — eleven rows done, one
current at day 12 in `Week II · P2`, seventy-two locked — where the same
bundle's `21 · Today` heads its page Day 41. The captures behind these tables
were taken with the seeded account's `createdAt` moved to day 12 so the row
states are the frames' own, and moved back immediately after.
