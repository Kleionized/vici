# Design references

The build's reference screenshots were **pasted directly into the Claude Code
session** rather than saved here, so this folder is a placeholder.

**To refine the visual design:** drop the actual reference image files into this
folder. The design tokens extracted from them — and how the two conflicting
reference styles were resolved — are documented in [`../DESIGN_NOTES.md`](../DESIGN_NOTES.md).

All visual tokens live in a single file: [`../src/lib/theme.ts`](../src/lib/theme.ts).
